# HearAssist - Спецификация

## 1. Project Overview

**Название:** HearAssist  
**Тип:** Android-приложение (усилитель звука/слуховой аппарат)  
**Версия:** 1.0.0
**Min SDK:** 29 (Android 10), **Target SDK:** 34

**Суть:** Трансляция звука с микрофона в наушники с низкой задержкой, обработкой и защитой слуха.

## 2. Technical Stack

- **Язык:** Kotlin
- **UI:** Jetpack Compose (Material Design 3)
- **Архитектура:** MVVM + Clean Architecture
- **Audio API:** AudioRecord + AudioTrack с PERFORMANCE_MODE_LOW_LATENCY
- **Асинхронность:** Kotlin Coroutines + Flow
- **DI:** Koin
- **Хранение:** DataStore Preferences
- **Min SDK:** 29, **Target SDK:** 34

## 4. Функциональность

### AudioEngine
- **Захват:** AudioRecord (44100Hz, 16bit, mono)
- **Обработка:**
  - Biquad EQ (5 полос: 60Hz, 250Hz, 1kHz, 4kHz, 16kHz)
  - Шумоподавление (высокочастотный фильтр)
  - Лимитер (-3dB, защита слуха)
- **Вывод:** AudioTrack (44100Hz, 16bit, стерео)
- **Задержка:** ~20-50 мс (low-latency mode)

### Настройки звука
| Функция | Диапазон |
|---------|----------|
| Громкость | 0-200% |
| Баланс | L100% - Центр - R100% |
| EQ (5 полос) | ±12 dB |

### Пресеты
| Пресет | Описание |
|--------|----------|
| Плоский | Без изменений |
| Речь | Усиление средних частот |
| На улице | Компенсация внешнего шума |
| Телевизор | Оптимизация для TV |

### Безопасность
- ✅ Лимитер на -3dB (обязательно включен по умолчанию)
- ✅ Предупреждение при громкости >100%
- ✅ Авто-пауза при входящем звонке
- ⚠️ Не является медицинским прибором

### Системные функции
- ✅ Foreground Service (работа в фоне)
- ✅ Таймер сна (15/30/60/120 мин)
- ✅ Оповещения о громких звуках (вибрация + вспышка)
- ✅ Сохранение настроек между сессиями
- ✅ Mono режим
