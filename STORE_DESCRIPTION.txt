# Описание для RuStore

## Краткое описание (до 80 символов):
Усилитель звука для слабослышащих

## Основное описание:

Aerophone — приложение-усилитель звука для людей с нарушениями слуха.

ОСНОВНЫЕ ФУНКЦИИ:
• Усиление звука в реальном времени с минимальной задержкой
• Настройка громкости до 200%
• Баланс между левым и правым наушником
• Моно режим для удобства
• Настройки частот (эквалайзер 5 полос)
• Предустановки для разных ситуаций: речь, улица, телевизор
• Шумоподавление
• Защита слуха — автоматически ограничивает громкость

ОПОВЕЩЕНИЯ:
• Вибрация при обнаружении громких звуков
• Вспышка экрана как визуальный сигнал
• Предупреждение при высокой громкости

УДОБСТВО:
• Таймер сна для автоматического отключения
• Все настройки сохраняются между сессиями
• Работа в фоновом режиме
• Автоматическая пауза при входящем звонке

ВНИМАНИЕ:
Приложение не является медицинским прибором и не заменяет профессиональный слуховой аппарат. Для подбора слухового аппарата обратитесь к специалисту.

РЕКОМЕНДАЦИИ:
• Используйте качественные наушники для лучшего результата
• Начните с низкой громкости и увеличивайте постепенно
• Не превышайте комфортный уровень громкости
